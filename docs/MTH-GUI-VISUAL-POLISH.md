# MTH GUI / Visual Polish

## Scope
Content-preserving visual polish across pricing plans, student requests (`/ads`), and shared card hierarchy — not a brand redesign.

## Changes
- **Plan cards**: equal-height hierarchy, stronger featured Pass card, solid badges, larger display prices, checkmark feature lists, unified monthly/annual toggle with audience tabs.
- **Student requests**: structured meta chips, title/description classes (no inline styles), clearer match state, loading copy “Loading requests…”, tighter empty state.
- **Home**: product-trio and free-summary cards use white raised surfaces instead of flat tint boxes.
- **Shared**: page heroes, results list spacing, tutor/ad row elevation.

## Verdict
**GUI polish shipped** — plans and request board read as professional SaaS cards while keeping existing brand colors and layout structure.
